# MoleculeDesk documentation

MoleculeDesk is an open-source package manager and runtime for computational biology models. It aims to make tools like Boltz, AlphaFold, ColabFold, Chai, and other molecular AI models easier to install and run on local machines, workstations, and remote GPU servers — without hand-rolling Python environments, CUDA setups, or model-specific commands.

```bash
npm install -g @moldesk/cli

moldesk doctor
moldesk install proteinmpnn
moldesk list --installed
```

MoleculeDesk is currently in **early development**. System detection, model discovery, and installing/running ProteinMPNN and LigandMPNN already work end-to-end; more model adapters (Boltz, AlphaFold, ColabFold, Chai) are in progress. Every page below states a model's current status plainly.

Each supported (or planned) model has its own page with setup details, requirements, and use cases:

- [LigandMPNN](/docs/models/ligandmpnn) — ligand- and multimer-aware sequence design (beta)

- [ColabFold](/docs/models/colabfold) — fast structure prediction (coming soon)
- [Chai](/docs/models/chai) — biomolecular structure prediction (coming soon)
