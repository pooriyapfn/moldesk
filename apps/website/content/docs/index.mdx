# MoleculeDesk documentation

MoleculeDesk is an open-source package manager and runtime for running molecular AI models locally. The CLI provides a consistent interface for supported models, while model pages distinguish models you can run today from planned integrations.

```bash
curl -fsSL https://moleculedesk.com/install.sh | sh

moldesk doctor
moldesk install proteinmpnn
moldesk list --installed
```

MoleculeDesk is currently in **early development**. System detection, model discovery, and installing/running Boltz-2, ProteinMPNN, and LigandMPNN already work end-to-end; DiffDock-L is coming soon (its adapter is implemented but not yet live-verified), and more model adapters (AlphaFold, ColabFold, Chai) are in progress. Every page below states a model's current status plainly.

## Models

Each supported (or planned) model has its own page with setup details, requirements, and use cases:

- [Boltz-2](/docs/models/boltz) — joint structure & binding-affinity prediction (Apple Silicon, NVIDIA CUDA)
- [DiffDock-L](/docs/models/diffdock) — blind small-molecule docking (NVIDIA CUDA)
- [BindCraft2](/docs/models/bindcraft2) — bounded local protein-binder campaigns (beta; Linux/NVIDIA)
- [RFD4-Proteina](/docs/models/rfd4-proteina) — protein, binder, enzyme and antibody design from condition specs (Linux/NVIDIA; run on Runpod)
- [OpenDDE Preview](/docs/models/opendde) — all-atom biomolecular co-folding (Apple Silicon, NVIDIA CUDA; upstream preview)
- [ProteinMPNN](/docs/models/proteinmpnn) — structure-conditioned sequence design (Apple Silicon, NVIDIA CUDA)
- [LigandMPNN](/docs/models/ligandmpnn) — ligand- and multimer-aware sequence design (Apple Silicon, NVIDIA CUDA)
- [AlphaFold](/docs/models/alphafold) — structure prediction (coming soon)
- [ColabFold](/docs/models/colabfold) — fast structure prediction (coming soon)
- [Chai](/docs/models/chai) — biomolecular structure prediction (coming soon)
