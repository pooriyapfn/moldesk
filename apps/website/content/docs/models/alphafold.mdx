# AlphaFold in MoleculeDesk

[AlphaFold](https://github.com/google-deepmind/alphafold) is DeepMind's protein structure prediction model.

<div className="not-prose my-6 rounded-md border border-border bg-white px-4 py-3 text-[14px] text-muted">
  <strong className="text-foreground">Status: planned.</strong> AlphaFold does not yet have a MoleculeDesk adapter or manifest — there's no install/run support today.
</div>

## Current status

MoleculeDesk's [model support table](https://github.com/pooriyapfn/moldesk#model-support) lists AlphaFold as **planned**. Follow the repository for updates, or see [Boltz-2](/docs/models/boltz), [ProteinMPNN](/docs/models/proteinmpnn), and [LigandMPNN](/docs/models/ligandmpnn) for models with adapters today.

## Contribute an adapter

Adding a model is documented in [`docs/adding-a-model.md`](https://github.com/pooriyapfn/moldesk/blob/main/docs/adding-a-model.md) in the repository — contributions are welcome.
