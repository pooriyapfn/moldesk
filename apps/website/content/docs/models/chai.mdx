# Chai in MoleculeDesk

[Chai-1](https://github.com/chaidiscovery/chai-lab) is an open-source biomolecular structure prediction model from Chai Discovery.

<div className="not-prose my-6 rounded-md border border-border bg-white px-4 py-3 text-[14px] text-muted">
  <strong className="text-foreground">Status: planned.</strong> Chai does not yet have a MoleculeDesk adapter or manifest — there's no install/run support today.
</div>

## Current status

MoleculeDesk's [model support table](https://github.com/pooriyapfn/moldesk#model-support) lists Chai as **planned**. See [Boltz-2](/docs/models/boltz), [ProteinMPNN](/docs/models/proteinmpnn), and [LigandMPNN](/docs/models/ligandmpnn) for models with adapters today.

## Contribute an adapter

Adding a model is documented in [`docs/adding-a-model.md`](https://github.com/pooriyapfn/moldesk/blob/main/docs/adding-a-model.md) in the repository — contributions are welcome.
