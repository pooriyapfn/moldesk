# Chai in MoleculeDesk

<ModelHero model="chai" />

**Status: planned.** Chai does not yet have a MoleculeDesk adapter or manifest — there's no install/run support today.

## Current status

MoleculeDesk's [model support table](https://github.com/pooriyapfn/moldesk#model-support) lists Chai as **planned**. See [Boltz-2](/docs/models/boltz), [OpenDDE Preview](/docs/models/opendde), [DiffDock-L](/docs/models/diffdock), [ProteinMPNN](/docs/models/proteinmpnn), and [LigandMPNN](/docs/models/ligandmpnn) for models you can run today.

## Contribute an adapter

Adding a model is documented in [`docs/adding-a-model.md`](https://github.com/pooriyapfn/moldesk/blob/main/docs/adding-a-model.md) in the repository — contributions are welcome.
