# BindCraft2 protein-binder campaigns

<ModelHero model="bindcraft2" />

## Overview

[BindCraft2](https://github.com/PacesaLab/BindCraft2) designs protein binders using
AlphaFold and ProteinMPNN/HyperMPNN. **Status: beta.** Install and bounded
campaigns work on real Linux/NVIDIA hardware (verified on an RTX 3090 and an A40).
Cancellation and repeat-run stability are not fully verified yet; see
[Verification status](#verification-status).

## Bounded campaigns

```json
{
  "targets": [{ "name": "my_target", "target_path": "target.pdb", "chains": "A" }],
  "modality": "binder",
  "binder_lengths": [50, 60],
  "number_of_final_designs": 1,
  "max_trajectories": 1,
  "resume": false
}
```

Both design count and trajectory budget must be positive integers. Target and
scaffold files stay within the campaign directory tree and are copied into the
run's immutable input area. Each invocation creates a fresh independent run.

```bash
moldesk run bindcraft2 campaign.json --param max_trajectories=2
```

Supported modalities: `binder`, `peptide`, `cyclic_peptide`, `VHH`, `ARP`.
Use `--param number_of_final_designs=1` or paired `min_length`/`max_length`
overrides. VHH/ARP use shipped scaffolds. Resume, automatic workers, arbitrary
preset files and modality combinations are not supported yet. CUDA is required;
CPU fallback is refused.

## Results

A campaign can exhaust its budget with **zero accepted designs**. That is a
successful bounded computation, recorded explicitly in `moldesk-summary.json`,
with trajectory/refolded records retained. Accepted structures appear only when
designs pass upstream filters. All collected outputs are checksummed in `run.json`.
Predicted candidates still require experimental validation.

## Verification status

Linux dependency resolution, a real installation and bounded campaigns on CUDA
are verified on an NVIDIA RTX 3090 and an NVIDIA A40 (see the benchmarks above).
On the A40, one GFP campaign aborted with a JAX `CUDA_ERROR_UNKNOWN` error and an
identical retry completed; the cause is unknown. Cancellation and the
forced no-GPU refusal path still need GPU testing. The repository's
`models/bindcraft2/README.md` contains source/asset provenance, license notes and
the live verification checklist. No macOS, MPS,
CPU, AMD or multi-GPU support is advertised for this integration.
