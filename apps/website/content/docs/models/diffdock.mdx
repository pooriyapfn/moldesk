# Run DiffDock-L for blind small-molecule docking

<ModelHero model="diffdock" />

## Overview

[DiffDock-L](https://github.com/gcorso/DiffDock) is an open-source diffusion model for blind small-molecule docking — predicting how a ligand binds a protein without a known binding pocket — released under the MIT license. It returns ranked 3D poses with a confidence score per pose, not a binding-affinity estimate. MoleculeDesk manages DiffDock-L's pinned CUDA-specific Python environment and model/language-model checkpoints so you don't have to hand-configure PyTorch Geometric's CUDA extension wheels yourself.

## What DiffDock-L is used for

DiffDock-L is designed for:

- **Blind protein-ligand docking** — predicting where and how a small molecule binds a protein, without requiring a known binding site.
- **Pose ranking** — generating multiple candidate 3D poses per complex, ranked by a learned confidence score.

DiffDock-L does **not** predict binding affinity — for that, see [Boltz-2](/docs/models/boltz).

## Requirements

| | |
| --- | --- |
| Model version | v1.1 |
| License | MIT |
| Python | 3.10, via `uv` |
| Platforms | `linux-x64` + NVIDIA CUDA only (required, no CPU path implemented for this model) |
| Input format | `.json` job file referencing a protein `.pdb` and a ligand `.sdf`/`.mol2` file, or a ligand SMILES string |
| Output | top pose (`.sdf`), all ranked poses (`.sdf`), a structured `poses_summary.json` with rank/confidence/atom-count |

DiffDock-L's pinned dependency stack (`torch==1.13.1+cu117` plus matching CUDA-built PyTorch Geometric extension wheels) is CUDA/Linux-specific with no Apple Silicon build available, and upstream exposes no CPU/device-selection flag at all — device selection is DiffDock-L's own automatic CUDA-or-CPU logic. MoleculeDesk requires a working CUDA install (checked at install-verification time) so a run is never silently downgraded to CPU.

## Job format

```json
{
  "jobName": "example-complex",
  "proteinPath": "protein.pdb",
  "ligand": { "path": "ligand.sdf" }
}
```

`ligand` accepts exactly one of `path` (an `.sdf`/`.mol2` file, resolved relative to the job file) or `smiles` (a SMILES string). `jobName` is optional and, if present, must be a safe identifier (letters, digits, `.`/`_`/`-`; no path separators or `..`) — it becomes a directory name under DiffDock-L's own output path.

## Source

MoleculeDesk pins DiffDock-L to a specific upstream commit on `main` — which already ships the current DiffDock-L architecture by default (upstream's own legacy v1 model is reachable only via an old git tag) — plus the exact model-weights release asset and the ESM2 language-model checkpoint DiffDock-L's own pipeline always downloads to compute protein embeddings. See the [upstream DiffDock repository](https://github.com/gcorso/DiffDock) for full details on the model itself.

## Verification status

`moldesk install diffdock` and `moldesk run diffdock` work end to end on Linux x64 with an NVIDIA GPU (verified on a RunPod NVIDIA A40, CUDA 12.8): the install takes about 10 minutes and a docking job takes about a minute. The install builds DiffDock-L's diffusion lookup tables once (they are cached under the install, so later runs do not repeat that step) and passes the CUDA check. Two jobs were run: the Trp-cage + aspirin example, and caffeine docked into the adenosine A2A receptor (PDB 5MZP, receptor only). Each produced ranked poses, `poses_summary.json` and the offline 3D report.

```bash
moldesk install diffdock
moldesk run diffdock examples/diffdock/job.json
```

Not yet verified: repeated runs for a median timing, cancelling a run mid-way, missing weights and malformed inputs, and whether predicted poses match experimental ligand positions. DiffDock-L's sequence-input path (`--protein_sequence`, ESMFold) is intentionally not supported: it needs `openfold`, which requires a CUDA 11.7 toolkit. Provide a protein structure file instead.

## FAQ

**Does `moldesk install diffdock` work today?**
Yes, on Linux x64 with an NVIDIA GPU (verified on an A40). It does not run on macOS or without CUDA.

**What license is DiffDock-L under?**
MIT, including the model weights. MoleculeDesk doesn't redistribute DiffDock-L's weights or the third-party ESM2 checkpoint it depends on; installing pins and downloads them from their original sources.

**Does DiffDock-L predict binding affinity?**
No — it predicts ranked docking poses with a confidence score. For binding-affinity prediction, see [Boltz-2](/docs/models/boltz).
