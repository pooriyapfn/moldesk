# Which molecular AI models run on Apple Silicon?

MoleculeDesk runs Boltz-2, OpenDDE Preview, ProteinMPNN, and LigandMPNN on Apple Silicon. The CLI detects your Mac's hardware with `moldesk doctor`. A model appearing in the registry does not mean its run path has been verified on every Mac.

## Current MoleculeDesk status

| Model | Purpose | Apple Silicon status |
| --- | --- | --- |
| [Boltz-2](/docs/models/boltz) | Structure and binding-affinity prediction | Install and MPS prediction verified on Darwin arm64 |
| [ProteinMPNN](/docs/models/proteinmpnn) | Structure-conditioned sequence design | Install and run supported on Darwin arm64 |
| [LigandMPNN](/docs/models/ligandmpnn) | Ligand- and multimer-aware sequence design | Install and run supported on Darwin arm64 |
| [OpenDDE Preview](/docs/models/opendde) | All-atom biomolecular co-folding | Install and MPS prediction verified on Darwin arm64 (upstream preview) |
| [DiffDock-L](/docs/models/diffdock) | Blind small-molecule docking | Linux x64 + NVIDIA CUDA only; not an Apple Silicon option |

AlphaFold, ColabFold, and Chai are listed as upcoming integrations; listing them is not a claim that they can currently be installed or run through MoleculeDesk. See [model compatibility](/docs/model-compatibility) for status definitions.

## Try the verified Boltz-2 path

```bash
curl -fsSL https://moleculedesk.com/install.sh | sh
moldesk doctor
moldesk install boltz
```

Continue with the [step-by-step Boltz-2 guide](/docs/guides/run-boltz-locally) for a real input and run command. The Apple Silicon adapter uses the [boltz-community MPS fork](https://github.com/Novel-Therapeutics/boltz-community); Linux x64 uses [upstream Boltz](https://github.com/jwohlwend/boltz) with its CUDA path. These are different pinned distributions, so hardware support and performance should not be inferred from one platform to the other.
