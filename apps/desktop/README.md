# MoleculeDesk Desktop (planned)

A future Tauri-based desktop app that wraps `@moldesk/core` — the same engine
used by the CLI — in a graphical interface for researchers who prefer not to
use the command line.

Not started yet. Tracked in [github.com/pooriyapfn/moldesk](https://github.com/pooriyapfn/moldesk).
