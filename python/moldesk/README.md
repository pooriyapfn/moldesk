# moldesk (Python)

Reserved package for Python-side helpers used by individual model runners
(e.g. Boltz's inference wrapper).

Not published on PyPI yet — MoleculeDesk's primary interface is the
TypeScript CLI (`npm install -g moldesk`). This package will only be
published once there's a genuine Python-facing use case, per
[PyPI's name-retention policy](https://docs.pypi.org/project-management/name-retention/).
